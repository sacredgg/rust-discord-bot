# Rust Discord Bot — статистика серверов Rust

Дискорд-бот, который показывает статистику Rust-сервера по адресу (`ip:port`):

- 🟢 Статус сервера (вкл / выкл)
- Игроки онлайн / максимум
- Очередь (если настроен BattleMetrics, см. ниже)
- Карта, версия, пинг, наличие пароля
- Команда для подключения `connect ip:port`
- Кнопка **Обновить** — перезапрашивает данные прямо в чате

## Как это работает

Данные получаются **прямым A2S-запросом** (UDP) к серверу — без API-ключей.
Бот сам пробует разные query-порты (`28015`, `+1`, `+2`, `+10`), поэтому работает
с большинством хостеров, включая Magic Rust и ему подобные.

Если UDP-запросы не проходят (часто бывает в офисах, учебных сетях или у провайдера),
бот автоматически переключается на **Steam Web API** (по HTTPS) — для этого нужен
бесплатный ключ Steam, см. ниже. Steam Web API также используется, чтобы находить
реальный сервер по адресу-редиректу (`3.magicrust.gg:28015`).

### Про очередь

A2S-протокол не отдаёт очередь. Очередь в Rust можно получить только через
BattleMetrics API, а он теперь **платный**. Если у тебя есть ключ BattleMetrics —
впиши его в `.env`, и поле «Очередь» появится автоматически. Без ключа очередь не показывается.

## Установка

1. **Создай бота** на https://discord.com/developers/applications
   - New Application → Bot → Reset Token → скопируй токен
   - Включи все Privileged Gateway Intents не нужно (бот работает только по слэш-командам)

2. **Пригласи бота** в свой сервер по ссылке (подставь свой `CLIENT_ID`):

   ```
   https://discord.com/api/oauth2/authorize?client_id=CLIENT_ID&permissions=0&scope=bot%20applications.commands
   ```

3. **Установи зависимости**:

   ```
   pip install -r requirements.txt
   ```

4. **Настрой токен**:

   ```
   copy .env.example .env
   ```
   Открой `.env` и впиши `DISCORD_TOKEN=твой_токен`

5. **Запасной источник (рекомендуется)**: если на твоей сети UDP к игровым портам
   заблокирован, добавь бесплатный ключ Steam:
   - зайди на https://steamcommunity.com/dev/apikey (нужен аккаунт Steam, бесплатно)
   - в поле «Domain Name» впиши что угодно, например `localhost`
   - скопируй ключ и впиши в `.env`: `STEAM_API_KEY=твой_ключ`

6. **Запусти**:

   ```
   python bot.py
   ```

## Использование

В дискорде напиши слэш-команду:

```
/server 87.236.31.33:28015
/server connect 87.236.31.33:28015
/server my-server.ru:28015
/server 104.143.2.214        # порт подставится автоматически (28015)
```

Бот ответит карточкой со статистикой и кнопкой «Обновить».

Если не знаешь точный адрес сервера — найди его по названию:

```
/search Magic Rust
```

Бот покажет список серверов с игровыми адресами (формат `connect адрес:порт`).
Затем запроси любой из них через `/server`.

> **Редиректы:** у некоторых хостеров (Magic Rust и т.п.) есть «удобные» адреса вида
> `3.magicrust.gg:28015` — это редиректы, они не отвечают на запросы статистики напрямую.
> Бот сам найдёт реальный сервер: запросит список Rust-серверов через Steam API,
> найдёт нужный по имени (домен + номер, например `magicrust` + `#3`) и покажет его
> данные вместе с реальным адресом для подключения.

## Структура

- `bot.py` — сам бот (команда `/server`, A2S-запрос, карточка, кнопка обновления)
- `requirements.txt` — зависимости
- `.env.example` — шаблон настроек (токен, опционально ключ BattleMetrics)

## Ограничения

- Нужен исходящий UDP-доступ к портам игровых серверов (в офисах/учебных сетях его часто блокируют — тогда A2S не работает, но на домашнем интернете проблем нет).
- Сервер должен отвечать на A2S-запросы (большинство публичных серверов отвечают).
